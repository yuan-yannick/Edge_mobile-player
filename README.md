# 长按加速播放 (Long-Press Video Speed)

> 在任意网页视频上 **长按屏幕 ≈0.35 秒 → 临时加速播放（默认 3 倍速），松手 → 自动恢复原速**。
>
> **本工具主要为移动端设计**：刷 B 站 / YouTube / 任意网页视频时，手指按住屏幕不动即可快速跳过冗长内容，松手回到原速，不打断播放、不误触暂停。桌面浏览器同样可用：电脑端按住 **Shift + →** 立即加速，松开任一键恢复。

## 功能特性

- 移动端：长按视频临时倍速（默认 3x），松手恢复原速，播放进度不受影响
- 电脑端：按住 **Shift + →** 立即加速，松开任一键恢复；无播放中视频时不拦截按键，不影响网站原有快捷键
- 短按（暂停/播放）、滑动（进度条/音量）等网站原生手势不受干扰
- 监听 `ratechange`，抵抗 YouTube 等网站对倍速的强制重置
- 屏蔽移动端长按视频弹出的「保存图像/复制」系统菜单
- 触摸点上方显示 `▶▶ 3.0x` 角标，可开关震动反馈
- 可调参数：倍速、触发延时（详见下文[设置说明](#设置说明)）

## 选择哪种形态？

同一个功能提供三种部署形态，**选一种即可，同时启用多个会互相抢倍速**：

| 形态 | 适用环境 | 特点 |
|---|---|---|
| **① 篡改猴脚本** `longpress-speed.user.js` ⭐ 移动端推荐 | 手机 Edge、手机 Firefox、Kiwi/Lemur 等支持扩展的手机浏览器；桌面端通用 | 装一次全站自动生效，篡改猴菜单里改设置 |
| **② Bookmarklet 书签** | 任何手机/桌面浏览器（包括不能装扩展的） | 零依赖，但每次刷新页面都要重新点一次书签 |
| **③ 浏览器扩展**（本目录） | 桌面 Edge / Chrome | 设置面板体验最好；手机端无法加载解压扩展 |

## 安装与使用

### 方式一：篡改猴脚本（移动端推荐）

**第 1 步 · 安装篡改猴 (Tampermonkey)**

- 手机 Edge：菜单 ⋯ → 扩展 → 获取扩展 → 搜索 **Tampermonkey** → 安装
- 手机 Firefox：菜单 → 附加组件 → 搜索 Tampermonkey → 安装
- 手机 Chrome 内核浏览器（Kiwi / Lemur 等）：内置扩展商店中装 Tampermonkey
- 桌面 Edge / Chrome / Firefox：对应扩展商店搜索 Tampermonkey

**第 2 步 · 安装本脚本（二选一）**

- **在线安装**：把 `longpress-speed.user.js` 放到任意可访问的静态地址（GitHub / Gitee 仓库的 raw 链接、个人服务器等），用浏览器打开该链接，篡改猴会自动弹出安装确认页 → 点「安装」
- **手动安装（无需任何托管）**：打开篡改猴管理面板 → 「＋」新建脚本 → 清空模板 → 把 `longpress-speed.user.js` 的全部内容粘贴进去 → 保存（Ctrl+S）

**第 3 步 · 使用**

打开任意视频网页正常播放：

- 手机：**手指按住视频约 0.35 秒**即加速，松手恢复
- 电脑：**按住 Shift + →** 立即加速，松开任一键恢复

修改设置：浏览器菜单 → 篡改猴图标 → 脚本下方会出现这些命令：

- ⏩ 长按倍速（当前 3x）— 点按弹窗输入，范围 1.25 ~ 16
- ⏱ 触发延时（当前 350ms）— 点按弹窗输入，范围 100 ~ 1000
- ⏸ 停用 / ▶ 启用
- 📳 震动反馈：开 / 关
- ↩ 恢复默认设置

设置保存后立即生效（同一标签页内的 iframe 也会同步）。

### 方式二：Bookmarklet 书签（无需装任何扩展）

1. 若改过 `bookmarklet.js`，先重新构建：`node build_bookmarklet.cjs`
2. 用手机浏览器打开 `bookmarklet.html` → 长按蓝色按钮 → 「添加到收藏」
3. 打开视频页 → 菜单 → 收藏 → 点一下「长按加速播放」书签 → 弹出提示即已激活
4. 长按视频加速，松手恢复。**每次刷新页面后需重新点一次书签**

### 方式三：桌面浏览器扩展（Edge / Chrome）

1. 打开 `edge://extensions`（Chrome 为 `chrome://extensions`）
2. 打开「开发人员模式」→「加载解压缩的扩展」→ 选择本文件夹
3. 点工具栏图标可改：启用开关、倍速（1.25–5x 滑条）、触发延时（150–800ms 滑条）、震动反馈
4. 触发方式与脚本版一致：手机长按视频，电脑按住 Shift + →
5. 设置通过浏览器账号在各设备间同步

## 如何测试

触发方式按设备区分：

- 手机 / 触摸屏：手指长按视频（鼠标点击无效）
- 电脑键盘：按住 `Shift + →`（要求页面有正在播放的视频）
- 需要在桌面模拟手机长按时：F12 → `Ctrl+Shift+M` 切换设备模拟 → 选一个手机机型 → 按住视频不动

验证清单：

| 操作 | 预期结果 |
|---|---|
| 手机按住视频 ≥ 0.35s | 出现 `▶▶ 3.0x` 角标（轻微震动），播放明显变快 |
| 松手 | 恢复原速，角标消失，且不会触发暂停/播放 |
| 电脑按住 Shift + → | 立即出现角标并加速，松开 Shift 或 → 任一键恢复 |
| 电脑单按 →（不加 Shift） | 不触发加速，网站原行为（如快进 5 秒）不变 |
| 页面无播放中视频时按 Shift + → | 按键不被拦截，网站原有快捷键正常 |
| 光标在输入框/评论框内按 Shift + → | 不劫持，仍是文本选择行为 |
| 短按视频一下 | 照常暂停/播放，不被劫持 |
| 按住后立即滑动 | 不触发加速；网站自身手势（进度/音量）正常 |
| 加速中修改倍速设置 | 角标与实际倍速实时更新 |
| 在 YouTube 上长按 | 倍速不会被网站改回 1x |
| 长按视频不松手 | 不弹出「保存图像/复制」系统菜单 |
| 切后台/页面失焦 | 自动恢复原速（保险机制） |

## 设置说明

| 参数 | 默认值 | 范围 | 说明 |
|---|---|---|---|
| 长按倍速 | 3.0x | 脚本 1.25–16；扩展 1.25–5 | 长按时切换到的临时倍速 |
| 触发延时 | 350ms | 脚本 100–1000；扩展 150–800 | 按住多久判定为「长按」 |
| 移动容差 | 10px | 固定 | 未触发前手指移动超过此距离视为滑动，取消判定 |
| 震动反馈 | 开 | 开/关 | 进入加速模式时震动 15ms（需设备支持） |

> 键盘加速（Shift + →）使用同一个「长按倍速」设置，且即时触发——「触发延时」仅对触摸长按生效。

Bookmarklet 版改参数：编辑 `bookmarklet.js` 顶部的 `speed` / `delay`，再运行 `node build_bookmarklet.cjs` 重新生成。

## 目录结构

| 文件 | 作用 |
|---|---|
| `longpress-speed.user.js` | **篡改猴脚本版**（移动端推荐入口） |
| `manifest.json` | 扩展清单（Manifest V3） |
| `content.js` / `content.css` | 扩展核心逻辑与样式（注入所有网页） |
| `background.js` | 扩展 Service Worker，安装时写入默认设置 |
| `popup.html` / `popup.css` / `popup.js` | 扩展设置弹窗 |
| `icons/` + `make_icons.py` | 扩展图标及生成脚本（纯 Python 标准库手写 PNG 编码） |
| `bookmarklet.js` | 书签版可读源码 |
| `build_bookmarklet.cjs` | 构建脚本：`node build_bookmarklet.cjs` 重新生成书签产物 |
| `bookmarklet.min.js` / `bookmarklet.url.txt` / `bookmarklet.html` | 书签版构建产物：压缩代码、`javascript:` URL、安装引导页 |

## 常见问题

**手机长按没反应？**
① 确认用的是触摸输入，鼠标点击无效；
② 篡改猴里确认脚本已启用、且没有对该网站禁用；
③ 个别网站把播放器放在特殊 iframe 里，极少数情况下脚本覆盖不到；
④ CSP 很严格的站点上角标/提示可能不显示，但加速功能本身不受影响。

**电脑按 Shift + → 没反应？**
① 需要页面里有**正在播放**的视频（全部暂停时按键不拦截，走网站原行为）；
② 光标焦点在输入框/评论框内时不劫持，点一下播放器区域再试；
③ 嵌入式 iframe 播放器需先点过播放器获得焦点。

**手机上每次刷新后又失效了？**
你用的是 Bookmarklet 版，这是书签的固有限制（脚本不持久）。换篡改猴脚本版即可一劳永逸。

**扩展、脚本、书签能同时用吗？**
不建议。三者逻辑相同，同时启用会互相抢 `playbackRate`，松手时可能恢复到错误的速度。选一个用。

**为什么是「松手恢复」而不是保持倍速？**
这就是设计意图：长按是「临时快进」——快速略过当前片段，松手立刻回到原本的观看节奏，不需要手动把倍速改回来。
